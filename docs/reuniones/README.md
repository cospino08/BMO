# Actas de reuniones

Una reunión semanal corta (máx. 30 min). El Líder crea el acta copiando [`plantilla.md`](plantilla.md) como `AAAA-MM-DD.md` y la sube el mismo día.

## Formato de la reunión

1. Cada área: qué terminó, qué hará y qué la bloquea (2–3 min por persona).
2. Revisar los riesgos del plan (sección 8).
3. Cambios a contratos o medidas: se aprueban aquí y luego se hace el PR.
4. Actualizar las casillas de tareas del plan.
